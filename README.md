# CypherNet - Decentralized Social Platform
Created with sleek dark-mode aesthetics, WebRTC Camera studio, Face Filters, Video/Voice calls, and Gemini-powered CypherAI.

## Features Included:
- Complete Social Feed with media uploads and replies
- Real-Time Camera Studio with CSS Filters (Glitch, Neon, Vintage, Thermal)
- Simulated Voice & Video Calls
- Encrypted Direct Messaging Interface
- Dynamic Stories Tray with Timer Progress
- Integrated Source Exporter
